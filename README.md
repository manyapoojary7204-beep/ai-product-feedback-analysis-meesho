# AI-Powered Product Feedback Analysis — Meesho
## Project Overview

An AI-assisted product research project analyzing 20 Meesho user reviews to identify recurring customer pain points, prioritize product improvements, and define measurable success metrics.

## Objective
Analyze customer reviews to identify the most common and impactful problems users experience and convert those insights into actionable product recommendations.

## Dataset
- Platform: Google Play Store
- App: Meesho
- Reviews analyzed: 20
- Negative reviews: 16
- Positive reviews: 4

## Tools Used
- Claude
- Google Play Store
- Notion
- GitHub

## Key Pain Points

1. Return pickup and refund delays
2. Delivery delays, non-delivery and cancellations
3. Customer support unresponsiveness

## Recommended Improvements
- Improve return and refund tracking
- Improve delivery and cancellation transparency
- Improve customer support escalation

## Success Metrics
- Return-to-refund cycle time
- Pickup/delivery success rate
- Customer support resolution rate
